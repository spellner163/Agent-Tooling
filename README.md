# Agent Tooling demo

Clickable prototype of Blueprint's agent-tooling feature for the Power Platform Community Conference. React + Vite + TypeScript, with the prototype's own stylesheet.

- `npm install`, then `npm run dev` to run it; `npm run build` to check it compiles.
- Read `PROJECT_BRIEF.md` first. It holds the rules the demo must keep and where each piece lives.
- `LOVABLE_KNOWLEDGE.md` is the text to paste into Lovable's Project Knowledge so its edits keep those rules.

Synthetic data, scripted model output. Not a product build.
